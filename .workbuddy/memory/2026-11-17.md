## 00:00–00:25 手机端（iPhone 16 Pro）侧栏空白 / 条目缺失

- **现象**：393×852 打开抽屉，面板列表只画到第 5 项（插件…微信BOT），「肥鱼日记/守岸人/记忆」不见；
  文字右侧被切；新会话按钮成一 26×199 灰色竖条。
- **根因**：`dsh-console-plugin@0.5.62` 的 `NARROW_CSS_TEXT`（`@media (max-width:520px)`，
  `#dsh-console-narrow-css`）里 8 条规则裸用 `[role=dialog]`：`width:100vw` + `> div{flex:1 1 auto;
  flex-direction:column}`。而 **dsh 0.2.2 手机抽屉的侧栏根节点就是 `role="dialog"`** →
  root 被撑到 393（抽屉只有 338，该插件另把 sidebarCol 设 fixed 86vw）→ 右侧 55px 被裁；
  logoRow/newSessionRow/scrollRegion/footArea 被 flex:1 均分 → footer 251、滚动区 161，
  面板列表 304 放不下，后 4 项被 footer 盖住；newSessionRow 变 column → 按钮竖条。
- **判据**：`[class*="sidebarCol"]` 宽 338 但 `[class*="quietBars"]`（root）宽 393；
  `newSessionRow` 的 computed `flexDirection==='column'` 且祖先**没有** `collapsed` 类。
- **修法**：8 条规则限定成 `div[class*="overlay"] > [role=dialog]`（只作用于它自己的弹窗）。
  `profile/patches/dsh-console-plugin@0.5.62.patch` 归档 + 复制到 profile patches +
  `pnpm-workspace.yaml` 的 `patchedDependencies` 登记 + `pnpm install`（沙箱 EIO 走 ssh localhost）+ 重启。
  `profile/install.sh` 加复制/登记，并删掉已退役的 `dsh-mijia-sidebar@1.0.1` 安装行。
- **验证手段（可复用）**：dsh 内置浏览器 `dom_cua_get_visible_dom` 返回空、截图超 10 MiB（不可用）。
  改用 Chrome headless + CDP：`--remote-debugging-port=9333`，node 22 全局 `WebSocket` 直连，
  `Emulation.setDeviceMetricsOverride{width:393,height:852,deviceScaleFactor:3,mobile:true}` +
  `Page.captureScreenshot`。脚本模板留在 /tmp/probe*.mjs（一次性）。
  定位样式来源用 `DOM.requestNode` + `CSS.getMatchedStylesForNode` + `CSS.getStyleSheetText`——
  比 grep 快，能直接读到注入的 CSS 文本。
- **修后**：root 280 / nav 264 / 九项全可见（y 116…420）/ 新会话 256×38 / footer 90；
  桌面 1440×900 无回归（drawer=null、sidebarCol 280、nav 264）。
- **注意**：0.5.76 与 0.5.77 同样带裸 `[role=dialog]`，升级会丢 patch，必须重做并在手机视口复查判据。
