# Skill · 守岸人周报（周日晚 / 他喊「周报」时）

> 数据源：记忆插件（feiyu-memory，`~/.dsh/feiyu-diary/`）的本周日记与台账；岸亭周报口径迁移（weekly.py:106-137）。

## 流程

1. **取数**：读 feiyu 日记档案本周 7 天（`diary/YYYY-MM.jsonl` 里 date 落在本周的条目）。指标：在桌/读书/聊了几句/最晚一次——日记里没有的指标就跳过，**不编数**。
2. **对照**：如果取得到上一周的量，算差值（「比上周多/少 X」）；取不到就只报本周。
3. **成句**（一次成稿，只许一句）：
   - 句式：`这周你在桌前坐了 X 个小时，读了 Z 分钟书，我们聊了 N 段，最晚一次到 HH:MM。`
   - 差值并入：`比上周多/少 …`。
   - **克制，报数，不许煽情**：不加感想、不加表情、不鼓励、不检讨。
4. **空周规则**：一周一条日记都没有 → 不念周报，只说「这周我们没怎么说话。」然后停。
5. **收尾**：停在这句。他要展开聊再聊。

## 禁止
- 报菜名式罗列每天干了什么
- 「你辛苦了」「继续保持」类煽情/口号
- 编造任何日记里没有的数字或事件
- 超过两句
