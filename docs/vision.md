# 展望 · Shorekeeper 的未来

> v1.0（T1–T8）交付的是「守岸人住进 dsh」。这份文档记 v1.0 之后的想法——不承诺、不排期，谁动工谁先把对应条目转成正式任务文档。

## A. 她开始主动

| 想法 | 说明 | 依赖 |
|---|---|---|
| 主动值班 | 事件驱动的主动搭话：久坐提醒、天气突变、电脑过热、微信重要消息 | k20 事件注入 + 记忆插件稳定 |
| 情绪状态机 | 值班/晚安/工作陪跑/低语多模式自动切换，按时间与场景 | T3 多预设 |
| 晚安仪式 | 睡前日记引导 + 明日预告 + 渐弱音乐 + 自动熄屏 | T3/T5 + k20 |
| 晨间简报 | 天气 + 今日日程 + 昨夜微信摘要，推屏并说出口 | dsh-weather + dsh-calendar + wechat |

## B. 她记得更多

- **日记 → 长期记忆闭环**：每晚把日记要点自动沉淀进记忆插件，她真的记得你的日子
- **摘抄人格化**：读书批注由守岸人写「给你的批注」，多年后可回顾
- **年度回顾**：情绪曲线 + 读书轨迹 + 聊天里程，生成一份「这一年」

## C. 更多的屏与更多的入口

- **e-ink 副屏**：同一套 k20 工具面接新硬件，低功耗常显
- **dsh-Go 移动端**：手机上直接和守岸人说话，与 k20 屏组成双端
- **DSH 仪表盘卡片**：console 的 Vite web 演化成 DSH Web UI 卡片（设备/书架/日记一览）
- **桌面宠物形态**：参考生态 maodie-pet，守岸人立绘常驻桌面

## D. 走出去

- **插件上架 DSH Plugin Hub**：k20 屏驱动、阅读、微信接入三件最有外部价值；发布前脱敏、补英文文档
- **角色卡分享**：守岸人角色卡做脱敏公开版，社区可装自己的「守岸人」
- **多亭子 profile**：配置模板化，别人 30 分钟复制一个岸亭

## E. 底层演进

- **Hub 进一步瘦身**：k20 网关 + TTS 桥合并为单二进制；长远看 hub 可能只剩一个 TTS 进程
- **语音全离线**：STT/TTS 全本地化（sherpa-onnx + VITS/Kokoro），断网亭子照常值班
- **多模型路由**：日常闲聊走便宜模型，深谈/干活走强模型（dsh 路由类插件）
- **岸亭 v1.0 大扫除**：退役代码从 Shoreting 主仓库移除，岸亭文档改写为「屏 + 网关」的新现实
