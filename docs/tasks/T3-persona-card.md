## 目标

persona.py / companion_flow.py / intents.py / companion_desk.py 的灵魂全部转写为 Tavern 生态资产：角色卡、世界书、多模式预设、周报/仪式 skill。人格一致性通过回归剧本校准——**零代码迁移**。

## 背景

守岸人的既定事实：第一人称（守岸人对漂泊者），官方口径「这个称呼就很好」。素材在 `reference/dock_hub/`：persona.py（599）、companion_flow.py（902）、intents.py（859）、companion_desk.py（731）、weekly.py。宿主是 T1 选定的 tavern 件。

## 步骤

### 阶段一：素材提炼（3–4h）
- [ ] 通读四份底料，提炼人格要素清单：口吻规则、称呼体系、情绪规则、禁忌话题
- [ ] 提炼意图分流策略：控制类意图（灯/屏/媒体/熄屏）路由到工具，陪伴类进剧情语境
- [ ] 提炼生活仪式流程：睡前日记引导、周日晚周报、晨间简报的对话脚本
- [ ] 每条要素标注出处（xx.py 第几段），防编造

### 阶段二：内容产出（5–7h）
- [ ] `content/shorekeeper-card/character.json`：Tavern V2 角色卡（人设、开场白、≥10 条示例对话）
- [ ] `content/shorekeeper-card/worldbook.json`：书桌亭世界观、三机设备名录、生活仪式规则、意图分流规则（关键词触发省 token）
- [ ] 多模式预设：值班（默认）/ 晚安 / 工作陪跑，切会话自动加载
- [ ] 周报 skill：守岸人从 memory 长期记忆中回顾本周（读了什么/做了什么/心情），生成周报的流程指令
- [ ] 意图分流写入世界书全局常驻条目

### 阶段三：校准（4–7h）
- [ ] 人格回归剧本 ≥20 条：早安/陪聊/查监控/被喊名字/打断/敏感话题/控制类混合句
- [ ] 对照 Hub 原行为逐条校准（有差距改卡不改剧本）
- [ ] 记忆插件接入（T1 选型件）：写入确认与检索调优
- [ ] 验收记录 + 卡片 git 版本化说明

## 交付物

## 验收标准
- [ ] 剧本 20 条全部通过（人格一致性 + 意图正确路由）
- [ ] 「小岸」称呼反应与 Hub 版一致
- [ ] 控制类指令不再触发剧情化回复

- 未来：日记 → 长期记忆闭环；角色卡脱敏公开分享
