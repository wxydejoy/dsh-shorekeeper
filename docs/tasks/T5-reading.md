## 目标

岸亭 books.py（758 行）的阅读能力在 dsh 里重生：书架、进度、摘抄、听书。历史数据无损迁入，守岸人能自然聊起「你上次读到那章了」。

## 背景

书架/进度/摘抄是岸亭私域能力，生态无现成件。数据格式对照 `reference/dock_hub/books.py`；听书依赖 dsh-keeper-voice 的流式朗读。

## 步骤

### 阶段一：数据迁移（2–3h）
- [ ] `migration/export_books.py`：books.py 数据 → JSON/Markdown（书名/作者/进度/摘抄/时间戳）
- [ ] 写前自动备份；幂等可重跑；对真实数据回归
- [ ] 数据落盘位置定为 `$DSH_HOME` 数据目录，导出格式文档化

### 阶段二：工具面（4–6h）
- [ ] `reading.shelf`：在读/读完/想读 + 进度 + 最近阅读排序
- [ ] `reading.progress`：更新进度（页码/百分比/章节），口语化输入解析（「看到 217 页了」）
- [ ] `reading.note`：摘抄与随想落库，可关联书与章节
- [ ] `reading.ask`：对读过的内容提问（书内摘要 + 记忆插件检索）
- [ ] 权限：全 read-only（数据修改经守岸人对话完成，仍走本插件写入口）

### 阶段三：听书与联动（4–5h）
- [ ] 听书模式：分段流式调 keeper-voice 朗读，可打断（复用 T4 的 stop 桥）
- [ ] 睡前听书联动 k20 字幕（可选开关）
- [ ] 记忆插件联动：读完一章自动沉淀摘要事实
- [ ] 单测 + 真实数据回归 + 验收记录

## 交付物
