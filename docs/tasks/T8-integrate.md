## 目标

新机器 30 分钟内从零到「完整亭子」；十条生活场景端到端全绿；岸亭 v1.0 发布。

## 步骤

### 阶段一：一键安装（3–4h）
- [ ] `profile/install.sh`：装 dsh（钉版本）→ 装生态插件清单 → 装 4 个自写插件 → 写入 cordis.patch.yml 默认值
- [ ] 全新目录演练安装（模拟新机器），问题回写脚本
- [ ] README「快速开始」补 30 分钟装机流程

### 阶段二：端到端剧本（4–5h）
十条场景逐条真机走查，每条留证据：
- [ ] ① 起床问天气（她答 + 推屏）
- [ ] ② 「把台灯调暗一点」（mihome）
- [ ] ③ 闲聊陪跑（人格一致性抽查 5 条）
- [ ] ④ 「放点白噪音/来首歌」（music）
- [ ] ⑤ 「我看到 217 页了」（reading）
- [ ] ⑥ 微信进来一条重要消息（摘要 + 提示）
- [ ] ⑦ 睡前仪式（日记引导 → 周报 → 听书 → 晚安）
- [ ] ⑧ 「晚安，帮我熄屏」（k20.lock 审批）
- [ ] ⑨ 全链路打断（说话中喊停立即停）
- [ ] ⑩ 断网降级（Hub 停机，插件不崩）

### 阶段三：发布（3h）
- [ ] 兼容矩阵：当前 dsh 版本 × 4 自写插件，写入 README
- [ ] 打 tag：`M1` `M2` `v1.0`；GitHub Release + 发布说明
- [ ] 决策记录：是否提交 DSH Plugin Hub（脱敏 + 英文 README 的工时另估）
- [ ] 岸亭仓库 v1.0 发布说明联动（shoreting 版本号语义协调）
